# Dossier de contrôle PC-2 — Tranche 2 : compte organisateur et mot de passe oublié

22/10/2026 · Arrêt prévu : point de contrôle de sécurité (mots de passe, sessions, jetons de réinitialisation).

## 1. Ce qui est prêt
- Inscription (email, mot de passe de 8 caractères au moins, **nom affiché**), connexion, déconnexion.
- Mot de passe oublié : demande, email E3 (boîte de test Mailpit), nouveau mot de passe, lien expiré ou déjà utilisé.
- Écrans O1 (7 états) ; page provisoire après connexion (« Vous êtes connecté : … », « Me déconnecter »).
- Sécurité : mots de passe argon2id ; jetons de 256 bits stockés hachés ; sessions révocables (cookie `HttpOnly`, `SameSite=Lax`) ; lien de réinitialisation à usage unique, 30 minutes, qui ferme toutes les sessions et les autres liens ; limites d'essais ; réponse identique pour un email inconnu (contenu et durée) ; requêtes d'un autre site refusées (S2).

## 2. Comment le valider (environ 10 minutes, sur l'ordinateur)
1. Deux terminaux : `pnpm dev:api` puis `pnpm dev:web`.
2. Ouvrir http://localhost:3000/organisateur/inscription : créer un compte → page « Vous êtes connecté : … ».
3. « Me déconnecter » → page de connexion. Essayer un mauvais mot de passe → bandeau rouge « Email ou mot de passe incorrect. » ; puis le bon → connecté.
4. Se déconnecter, « Mot de passe oublié ? », saisir l'email → « Regardez votre boîte email ».
5. Ouvrir la boîte de test http://localhost:8025, ouvrir l'email « Réinitialisez votre mot de passe Gatio », cliquer « Choisir un nouveau mot de passe ».
6. Saisir un nouveau mot de passe → « Mot de passe modifié » → se connecter avec le nouveau.
7. Recliquer le même lien dans l'email → « Ce lien n'est plus valable… ».
8. Refaire l'étape 4 avec un email qui n'existe pas → même écran, aucun email dans Mailpit.

## 4. Décisions à prendre
| # | Décision | Recommandation |
|---|---|---|
| D1 | **Inscription** : elle dit « Un compte existe déjà avec cet email » ; quelqu'un peut donc vérifier si un email est inscrit (en créant un vrai compte quand il ne l'est pas).
