## 2. Comment le valider
1. Dans un terminal, à la racine : `pnpm dev`, puis ouvrir http://localhost:3000 → « Le service fonctionne. »
2. `docker compose stop postgres`, recharger la page → message d'indisponibilité ; `docker compose start postgres` → de nouveau « fonctionne ».
3. Ctrl+C, puis `pnpm verify` → tout vert (environ 2 minutes ici).
