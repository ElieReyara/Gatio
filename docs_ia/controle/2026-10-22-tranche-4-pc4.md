# Dossier de contrôle PC-4 — Tranche 4 : publication, page publique, recherche, annulation et report, support

22/10/2026 · Arrêt prévu : seul le responsable peut juger l'aperçu de partage et le rendu des pages publiques ; données manquantes (contacts du support).

## 1. Ce qui est prêt
- **Publication** depuis la page d'un événement (écran O5) : publier (moyen de versement exigé), lien de vente à copier ou à partager sur WhatsApp, dépublier.
- **Report** (maquette proposée, validée en principe) : confirmation, bandeau, nouvelle date, republication ; **annulation** définitive avec confirmation.
- **Page d'accueil = liste des événements** (B1) : filtres ville, date, type ; « À partir de … » ; « Voir plus » au-delà de 20.
- **Page d'un événement** (B2) `/e/…` : image, date, lieu, organisateur, rappel de prudence, état de chaque catégorie (disponible, bientôt en vente avec la date d'ouverture, vente terminée, épuisé), bandeaux « annulé » et « reporté » (« Date à confirmer »), lien « Contacter le support ».
- **Page de support** : WhatsApp et email, message pré-rempli avec le nom et le lien de l'événement.
- **Journal d'audit** : report, annulation, republication, changement de date pendant un report.

## 2. Comment le valider
### A. Sur l'ordinateur (environ 15 minutes)
1. Dans `.env`, renseigner `SUPPORT_WHATSAPP` (ex. `23566000000`) et `SUPPORT_EMAIL`, puis `pnpm dev:api` et `pnpm dev:web`.
2. Ouvrir un de vos événements (organisateur) : **Publier** → bandeau vert, lien de vente ; **Copier le lien**.
3. Ouvrir http://localhost:3000 (liste) : l'événement y est ; essayer les filtres et les types.
4. Ouvrir le lien de vente : vérifier la page (catégories, rappel, « Contacter le support » → page de support → WhatsApp et email s'ouvrent avec le message).
5. Revenir à l'organisateur : **Reporter** → la page publique affiche le bandeau orange et « Date à confirmer » ; l'événement sort de la liste. Choisir une nouvelle date → **Republier** → de nouveau en vente.
6. **Annuler** (avec confirmation) → bandeau rouge ; plus rien de modifiable.

### B. Aperçu de partage dans WhatsApp (critère de la roadmap)
1. Mettre une image à l'événement ; `pnpm dev:api` + `pnpm start:web` ; tunnel `cloudflared tunnel --url http://127.0.0.1:3000`.
2. Mettre l'adresse du tunnel dans `.env` : `SITE_URL=https://….trycloudflare.com`, puis relancer `pnpm start:web`.
3. Coller `https://….trycloudflare.com/e/…` dans une conversation WhatsApp : le titre et l'image doivent apparaître. Si l'image manque (format WebP), je prévois une variante JPEG pour l'aperçu (dette D13).
